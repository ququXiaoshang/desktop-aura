# 灵动桌面 Aura（desktop-aura）

一个 Windows 桌面美化工具：让桌面图标「灵动」起来——鼠标碰到图标就上浮，并支持收纳分组、壁纸毛玻璃质感。

> 当前版本 **0.2.0（第二期）**：在第一期基础上补齐了正式图标、设置面板、图标收纳分组和壁纸毛玻璃。

---

## 一、功能总览

| 功能 | 说明 | 状态 |
|---|---|---|
| 图标 hover 上浮 | 鼠标碰到图标上浮 + 放大 + 投影，带弹性缓动 | ✅ |
| 点击启动 | 点击图标启动对应程序 | ✅ |
| 灵动/原生模式切换 | 托盘勾选「启用灵动桌面」一键切换，两套图标不重叠 | ✅ |
| 鼠标穿透 | 图标之外区域穿透，不影响右键桌面、框选 | ✅ |
| 复刻系统布局 | 图标大小/间距/字体自动读取系统设置，和原生桌面一致 | ✅ |
| 正式图标 | 托盘 + 应用图标（蓝紫渐变） | ✅ |
| 设置面板 | 托盘「设置…」，滑块实时调上浮高度/放大/速度/弹性 | ✅ |
| 图标收纳分组 | 按规则分组显示为可折叠盒子 | ✅ |
| 壁纸毛玻璃 | hover 图标时卡片显示壁纸对应区域的模糊背景 | ✅ |

## 二、技术栈与架构

- **Electron**（透明无边框覆盖层窗口 + 设置面板窗口 + 托盘）
- **原生 HTML / CSS / JavaScript**（无前端框架，代码简单好维护）

### 进程结构

```
┌─────────────────────────────────────────────┐
│  主进程 main.js                             │
│  · 读取桌面 .lnk → 提取真实图标             │
│  · 读取注册表（图标间距/大小/壁纸路径）     │
│  · 创建透明全屏覆盖层（showInactive 不抢焦点）│
│  · 托盘菜单、设置面板窗口                   │
│  · 调用 PowerShell 脚本（读参数/隐藏图标）  │
└──────────────┬──────────────────────────────┘
               │ IPC（contextBridge 安全桥接）
┌──────────────▼──────────────────────────────┐
│  渲染进程 renderer/                         │
│  · index.html（覆盖层）+ renderer.js        │
│  · settings.html（设置面板）+ settings.js   │
└─────────────────────────────────────────────┘
```

## 三、运行方法

```powershell
cd C:\Users\LENOVO\desktop-aura
npm install     # 首次安装 Electron
npm start       # 启动
```

启动后默认进入**灵动桌面模式**（自动隐藏系统图标、显示灵动图标）。托盘菜单可切换模式、打开设置、刷新图标、退出。

> 退出应用时会自动恢复系统桌面图标，不会让桌面变空。

## 四、配置说明（config.json）

```json
{
  "hover": {
    "liftY": 10,       // 上浮高度（px），越大浮得越高
    "scale": 1.07,     // 放大倍数，1.0 = 不放大
    "duration": 0.28,  // 动画时长（秒），越小越快
    "easing": "cubic-bezier(0.22, 1.4, 0.36, 1)"  // 弹性曲线
  },
  "icons": {
    "offsetX": 8,      // 图标区整体左右偏移（微调对齐）
    "offsetY": 8       // 图标区整体上下偏移
  },
  "groups": [
    { "name": "开发工具", "match": ["code", "visual studio", "git", "python"] },
    { "name": "游戏", "match": ["steam", "game"] }
  ]
}
```

- `hover` 也可通过托盘「设置…」面板实时调整（自动写回 config.json）。
- `groups` 为空数组 `[]` 时不分组，图标散落（复刻系统桌面）；配置了分组后按关键词归组，未匹配的进「其他」。
- 图标大小、间距是**自动读取系统值**的，不用手动配置。

## 五、核心原理

1. **图标来源**：主进程用 `app.getFileIcon()` 通过系统 Shell 提取每个快捷方式的真实图标（含自定义图标），转成 dataURL 给前端渲染。
2. **覆盖层不抢焦点**：透明全屏窗口用 `showInactive()` 显示 + `focusable: false`，作为桌面上的安静覆盖层，不抢占键盘焦点。
3. **鼠标穿透 + 局部可点**：窗口默认 `setIgnoreMouseEvents(true, { forward: true })`，前端在 `mousemove` 里做命中检测，鼠标进入图标或分组标题才切换为可交互。
4. **隐藏系统图标**：改注册表 `HideIcons` 的同时，直接 `ShowWindow` 控制系统图标层（DefView）的可见性，立即生效、不重启资源管理器、不影响覆盖层。
5. **毛玻璃**：读取壁纸文件 → 缩放 → hover 图标时用伪元素显示壁纸对应区域的模糊背景（`blur` + `background-position` 对齐），视觉上像液态玻璃折射壁纸。

## 六、已知限制

- **多屏**：目前只覆盖主屏，副屏未适配。
- **动态壁纸**：若用 Wallpaper Engine 等动态壁纸，毛玻璃使用的是其静态备份图，可能与实时画面略有差异。
- **分组为手动配置**：目前分组靠 config.json 的关键词匹配，尚未提供拖拽归类/重命名/拖动盒子位置的图形化操作（后续优化）。
- **毛玻璃为简化版**：只做壁纸模糊，不做实时折射。

## 八、常见问题

**Q：`npm install` 下载 Electron 很慢或失败？**
```powershell
npm config set electron_mirror "https://npmmirror.com/mirrors/electron/"
npm install
```

**Q：想恢复系统桌面图标？**
托盘取消「启用灵动桌面」，或运行：
```powershell
powershell -File scripts/hide-icons.ps1 0
```

**Q：图标 hover 没反应？**
确认托盘「启用灵动桌面」已勾选；或重启应用。

**Q：想换回图标散落（不分组）？**
把 config.json 里的 `groups` 改成 `[]`，重启应用。
