## 四、关键踩坑记录（真实经验）

1. **贴桌面方案**：`SetParent` 到 WorkerW 会被 Electron 重置 → 改用 `showInactive` 顶级窗口
2. **隐藏系统图标**：`ShowWindow` 会破坏图标列表（ListView）→ 改 `HideIcons` 注册表 + `FWF_NOICONS` 标志位 + 重启 explorer
3. **真实图标提取**：`getFileIcon(.lnk)` 拿不到真实图标 → 解析 .lnk 目标再提取；中文路径编码问题 → 统一 UTF-8
4. **单实例锁失效**：userData 目录因 productName 变化而分裂 → 强制统一路径
5. **开机自启失效**：测试任务计划方案时误删 Run 键 → 重新写入 + 自检恢复机制
6. **微信更新后图标空白**：exe 更新时被锁定导致提取失败 → 手动强刷 + 自动检测双保险
